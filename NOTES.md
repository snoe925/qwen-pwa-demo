## What this is
Offline-first notes PWA, no build step, designed for GitHub Pages project sites.
Files: index.html, styles.css, app.js, sw.js, manifest.webmanifest, offline.html, .nojekyll, icons/, tools/make_icons.py

## Key decisions
- All paths relative; manifest `start_url`/`scope` = `./` → works at `https://snoe925.github.io/<repo>/`
- SW: versioned cache `quicknotes-v1`, precached app shell, network-first for navigations with offline.html fallback, cache-first for assets. **Bump VERSION in sw.js on every release.**
- Notes stored in localStorage under key `quicknotes.v1`
- Icons (192, 512, maskable-512, apple-touch 180) generated by `python3 tools/make_icons.py` (needs PIL)
- Install button via `beforeinstallprompt`; `?action=new` shortcut focuses composer
