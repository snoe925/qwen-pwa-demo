## Key decisions
- All paths relative; manifest `start_url`/`scope` = `./` → works at `https://snoe925.github.io/<repo>/`
- SW: versioned cache `quicknotes-v5`, precached app shell, network-first for navigations with offline.html fallback, cache-first for assets. **Bump VERSION in sw.js on every release.**
- Notes stored in localStorage under key `quicknotes.v1`
- Icons (192, 512, maskable-512, apple-touch 180) generated by `python3 tools/make_icons.py` (needs PIL)
- Install button via `beforeinstallprompt`; `?action=new` shortcut focuses composer

## Breakout game
- Launched by the "Play" card at the top of the notes page: a full-screen overlay (`#game-overlay` in index.html), so an installed PWA always has a way back out via the × button
- `game.js`: canvas 2D, requestAnimationFrame, all motion scaled to the stage size and clamped delta; bricks store row/col so a resize (rotation) re-lays them out
- Controls: a dedicated touch strip is drawn along the bottom of the canvas (`G.stripH`); the playfield is `G.playH = H - stripH` and the paddle sits just above it, so a thumb dragging in the strip never covers the paddle. Tap to launch; arrow keys + space on desktop. Auto-pauses when the page is hidden
- Best score in localStorage under `quicknotes.breakout.best.v1`
- `game.js` is in the SW app shell, so the game plays fully offline

## Wave generator
- "Wave" card opens `#wave-overlay`: **4 voices** (4 `OscillatorNode`s, each with its own `GainNode`) mixed through one `masterGain` into the destination. Waveform applies to all voices (`sine` / `square` / `sawtooth`)
- Defaults: root 440 Hz (A4), then +7 / +12 / +19 semitones (E5 / A5 / E6); per-voice mix faders (100 / 60 / 45 / 32) and master volume
- Full-screen modal built like the game overlay: header with the live "wave · voice count" line and the × button, a scrolling body panel, and Play pinned at the bottom
- Each voice row shows note name + Hz, ± semitone buttons and a 0–100% mix fader; the big readout shows the root voice; header shows active-voice count
- AudioContext is created lazily inside the Play tap (iOS requires a gesture), and resumed if iOS suspended or interrupted it; closing the panel or hiding the page stops the tone and suspends the context
- Gain ramps (50 ms in, 60 ms out) so starting and stopping do not click; peak is capped at 0.9 master and 0.12 per voice
- `wave.js` is in the SW app shell too, so the generator works offline
