## What this is
Offline-first notes PWA, no build step, designed for GitHub Pages project sites.
Files: index.html, styles.css, app.js, sw.js, manifest.webmanifest, offline.html, .nojekyll, icons/, tools/make_icons.py, plus games (game.js / wave.js / 2048.js / memory.js / tetris.js)

## Key decisions
- All paths relative; manifest `start_url`/`scope` = `./` → works at `https://snoe925.github.io/<repo>/`
- SW: versioned cache `quicknotes-v11`, precached app shell, network-first for navigations with offline.html fallback, cache-first for assets. **Bump VERSION in sw.js on every release.**
- Notes stored in localStorage under key `quicknotes.v1`
- Icons (192, 512, maskable-512, apple-touch 180) generated by `python3 tools/make_icons.py` (needs PIL)
- Install button via `beforeinstallprompt`; `?action=new` shortcut focuses composer

## Breakout game
- Launched by the "Play" card at the top of the notes page: a full-screen overlay (`#game-overlay` in index.html), so an installed PWA always has a way back out via the × button
- `game.js`: canvas 2D, requestAnimationFrame, all motion scaled to the stage size and clamped delta; bricks store row/col so a resize (rotation) re-lays them out
- Controls: a dedicated touch strip is drawn along the bottom of the canvas (`G.stripH`); the playfield is `G.playH = H - stripH` and the paddle sits just above it, so a thumb dragging in the strip never covers the paddle. Tap to launch; arrow keys + space on desktop. Auto-pauses when the page is hidden
- Best score in localStorage under `quicknotes.breakout.best.v1`
- `game.js` is in the SW app shell, so the game plays fully offline

## 2048
- Launch card + full-screen overlay (`#2048-overlay`): DOM grid of 4×4 cells (`#2048-board`), `2048.js`
- Direction slides use the classic "process cells in arrival order, merge once" algorithm; `7→2048` tile colors; new 2/4 spawned after every move (90/10)
- Score/best in localStorage under `quicknotes.2048.best.v1`; win at 2048 (option to keep going) and stall detection; swipe + arrow keys
- `2048.js` is in the SW app shell, so it works offline

## Memory Match
- Launch card + full-screen overlay (`#memory-overlay`): DOM grid of 16 cards (`#memory-grid`), `memory.js`
- 8 pairs, shuffled deck, two-card flip with 800 ms pause before unmatching; moves and matched count in the HUD; best moves in localStorage under `quicknotes.memory.best.v1`
- Reinserted into the grid on every click (small grid, full re-render is cheap)

## Tetris
- Launch card + full-screen overlay (`#tetris-overlay`): canvas 10×20 (`#tetris-canvas`), `tetris.js`
- 7-piece bag (7 shuffled per cycle), rotate with simple wall-kicks, ghost-free, gravity speed ramps (4 lines/level, 800 ms → 90 ms min), soft/hard drop, line-clear scoring (100/300/500/800 × level)
- Controls: Left/Right/Rotate/Drop/Pause/Restart buttons + arrow keys/space/up; auto-pauses when the page is hidden
- Best score in localStorage under `quicknotes.tetris.best.v1`; `tetris.js` is in the SW app shell, so it works offline

## Dino Runner
- Launch card + full-screen overlay (`#dino-overlay`): canvas (`#dino-canvas`), `dino.js`
- Auto-run, tap/space to jump, AABB collision with striped obstacles, speed ramps 140 → 460 px/s; distance in meters, best in localStorage under `quicknotes.dino.best.v1`
- Canvas-drawn dino with animated legs; auto-pauses on tab hide (Resume message)

## Dodge
- Launch card + full-screen overlay (`#dodge-overlay`): canvas (`#dodge-canvas`), `dodge.js`
- Mines fall from the top (hexagons); the shield slides via pointer drag / arrow keys; correct circle-rect collision, invincibility window and screen shake on hit
- Score = mines dodged; 3 lives; best in localStorage under `quicknotes.dodge.best.v1`; auto-pauses on tab hide

## Wave generator
- "Wave" card opens `#wave-overlay`: **4 voices** (4 `OscillatorNode`s, each with its own `GainNode`) mixed through one `masterGain` into the destination. Waveform applies to all voices (`sine` / `square` / `sawtooth`)
- Defaults: root 440 Hz (A4), then +7 / +12 / +19 semitones (E5 / A5 / E6); per-voice mix faders (100 / 60 / 45 / 32) and master volume
- Full-screen modal built like the game overlay: header with the live "wave · voice count" line and the × button, a scrolling body panel, and Play pinned at the bottom
- Each voice row shows note name + Hz, ± semitone buttons and a 0–100% mix fader; the big readout shows the root voice; header shows active-voice count
- AudioContext is created lazily inside the Play tap (iOS requires a gesture), and resumed if iOS suspended or interrupted it; closing the panel or hiding the page stops the tone and suspends the context
- Gain ramps (50 ms in, 60 ms out) so starting and stopping do not click; peak is capped at 0.9 master and 0.12 per voice
- `wave.js` is in the SW app shell too, so the generator works offline
